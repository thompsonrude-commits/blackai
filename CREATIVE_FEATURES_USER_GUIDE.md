## 🎵 MUSIC LYRICS

### How to Generate Lyrics

Simply type a request like:
- "Write lyrics about love in Yoruba"
- "Create a hip-hop song about family in Igbo"
- "Compose lyrics for a traditional Edo song"
- "Make a pop song about dreams in Hausa"

### What You'll Get
✅ Complete song with verse, chorus, bridge, and outro  
✅ Authentic language and cultural references  
✅ Consistent rhyme scheme and meter  
✅ Memorable, singable hooks  
✅ Emotional progression throughout  

### Tips for Better Lyrics
1. **Be specific about mood**: "sad love song", "uplifting anthem", "party vibes"
2. **Mention genre**: "hip-hop", "afrobeats", "traditional", "pop"
3. **Add context**: "about overcoming challenges", "celebrating culture", "telling a story"
4. **Specify language**: "in Yoruba", "in Igbo", "in Edo", "in Hausa"

### Example Requests
```
"Write uplifting lyrics about education in Igbo with hip-hop vibes"
"Create romantic lyrics about love in Yoruba with afrobeats style"
"Compose traditional lyrics about family in Edo with cultural elements"
"Make party lyrics about celebration in Hausa with modern pop sound"
```

## 📝 POETRY

### How to Generate Poetry

Type requests like:
- "Write a poem about nature in Igbo"
- "Create a haiku about love in Edo"
- "Compose a sonnet about family in Yoruba"
- "Make free verse poetry about dreams in Hausa"

### What You'll Get
✅ Complete poem (minimum 12 lines)  
✅ Authentic language and imagery  
✅ Vivid metaphors and sensory details  
✅ Consistent meter or rhythm  
✅ Emotional depth and resonance  

### Poetry Forms Available
- **Free Verse** - No specific structure, natural flow
- **Haiku** - 3 lines, 5-7-5 syllable pattern
- **Sonnet** - 14 lines, specific rhyme scheme
- **Acrostic** - First letter of each line spells a word
- **Limerick** - 5 lines, humorous, AABBA rhyme
- **Blank Verse** - Unrhymed iambic pentameter

### Tips for Better Poetry
1. **Specify the form**: "haiku", "sonnet", "free verse", "acrostic"
2. **Mention imagery**: "nature", "emotions", "colors", "sounds"
3. **Add theme**: "love", "loss", "joy", "wisdom", "culture"
4. **Specify language**: "in Yoruba", "in Igbo", "in Edo", "in Hausa"

### Example Requests
```
"Write a haiku about the moon in Yoruba"
"Create a sonnet about love in Igbo with romantic imagery"
"Compose free verse poetry about nature in Edo"
"Make an acrostic poem spelling FAMILY in Hausa"
```

## 🎼 SUNO PROMPTS

### How to Generate Suno Prompts

Request prompts like:
- "Create a Suno prompt for an upbeat summer song"
- "Generate a Suno prompt for a sad love ballad in Yoruba"
- "Make a Suno prompt for a hip-hop track about culture"
- "Create a Suno prompt for a traditional Edo song"

### What You'll Get
✅ Detailed, actionable music prompt  
✅ Specific musical elements (genre, BPM, instrumentation)  
✅ Emotional descriptors and mood  
✅ Vocal characteristics and style  
✅ Production details  
✅ Lyrical themes and concepts  

### How to Use Suno Prompts
1. Copy the generated prompt
2. Go to [Suno.ai](https://suno.ai)
3. Paste the prompt into the music generation interface
4. Click "Generate" to create the music
5. Listen and refine as needed

### Tips for Better Suno Prompts
1. **Specify genre**: "afrobeats", "hip-hop", "pop", "reggae", "traditional"
2. **Mention mood**: "uplifting", "melancholic", "energetic", "calm", "romantic"
3. **Add instrumentation**: "acoustic guitar", "synths", "drums", "strings"
4. **Specify vocals**: "male vocals", "female vocals", "duet", "rap", "singing"
5. **Include BPM**: "120 BPM", "slow", "fast", "moderate tempo"

### Example Requests
```
"Create a Suno prompt for an upbeat afrobeats song about celebration"
"Generate a Suno prompt for a sad love ballad with acoustic guitar"
"Make a Suno prompt for a hip-hop track about cultural pride"
"Create a Suno prompt for a traditional Edo song with modern production"
```

## 🎯 ADVANCED TIPS

### Combining Parameters
You can specify multiple parameters in one request:

```
"Write uplifting lyrics about education in Igbo with hip-hop vibes, 
mood: inspirational, style: contemporary, genre: afrobeats"
```

### Refining Content
If you don't like the first result, ask for variations:

```
"Write the same lyrics but with a different rhyme scheme"
"Create a more traditional version of that poem"
"Tell the story from a different character's perspective"
"Make the Suno prompt more energetic and upbeat"
```

### Mixing Languages
You can request content in multiple languages:

```
"Write lyrics with Yoruba verses and English chorus"
"Create a poem mixing Igbo and English"
"Tell a story with Edo dialogue and English narration"
```

### Adding Context
Provide more context for better results:

```
"Write lyrics about overcoming challenges, inspired by my personal journey"
"Create a poem about nature, focusing on the beauty of Nigerian landscapes"
"Tell a story about the importance of education in Igbo culture"
```
