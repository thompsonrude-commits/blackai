## NOTES

1. **Edo Language:** The Edo language (4 million+ speakers) is notably absent from both vocabulary files. It appears to use a separate repository system (`repository.ts`).

2. **Dialect Handling:** Some languages have multiple dialect entries (e.g., Hausa, Yoruba, Igbo). Each dialect ID is treated as a separate language entry in the system.

3. **Duplicate Entries:** Some languages appear in multiple regions:
   - **Igala:** Listed in both South-East (Anambra) and North-Central (Kogi)
   - **Igede:** Listed in both South-East (Enugu) and North-Central (Benue)
   - **Gbagyi:** Listed in both North-Central (Niger) and North-West (Kaduna)
   - **Tyap/Kataf:** Listed in both North-Central (Plateau) and North-West (Kaduna)

4. **Coverage Gaps:** The South-West region has the lowest coverage (11%), despite containing Yoruba (40 million+ speakers). This is because only the main Yoruba language has a vocabulary, but not its major dialects.
