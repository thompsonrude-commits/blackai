## 📱 Sidebar Navigation

The sidebar appears automatically when you're logged in on the home or chat pages. It includes:

### Features Available:

1. **New Chat Button** 
   - Start a fresh conversation
   - Clears current chat history

2. **Chat History**
   - View all your previous chat sessions
   - Click any session to restore it
   - Sessions are auto-saved with timestamps
   - Shows session titles based on first message

3. **Session Management**
   - Delete old sessions (trash icon)
   - Sessions are organized by date
   - Each session has a unique ID

4. **User Account Menu**
   - View profile information
   - Sign out option
   - Account settings

### Sidebar Controls:

- **Collapse/Expand:** Click the chevron icon (< >) to toggle sidebar
- **Mobile:** Sidebar is hidden by default on mobile, tap menu icon to show
- **Auto-close on mobile:** Sidebar closes automatically after selecting a session

## 🛠️ Troubleshooting

### Sidebar Not Showing?
- Check if you're logged in (sign in with Google)
- Verify you're on home (`/`) or chat (`/assistant`) page
- Try refreshing the page (Ctrl + Shift + R)
- Check browser console for errors

### Can't See Chat History?
- Ensure you're logged in with the same account
- History is tied to your Firebase user ID
- Anonymous browsing doesn't save history

### Admin Routes Not Working?
- Verify you're logged in as admin
- Check email matches exactly: `obosathompsons@gmail.com`
- Try logging out and logging back in
- Clear browser cache if needed
