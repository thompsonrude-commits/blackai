# GPU Infrastructure Setup Guide for 9JAI Image Generation

This guide walks you through setting up the self-hosted GPU infrastructure for REAL AI image generation.

---

## OPTION 1: RunPod GPU (Recommended for Testing)

RunPod provides on-demand GPU instances with pre-built templates. Perfect for testing before investing in hardware.

### Step 1: Create RunPod Account

1. Go to https://runpod.io
2. Sign up for an account
3. Add credits ($10 minimum) via Credit Card or Crypto

### Step 2: Deploy ComfyUI Template

1. Go to **Pods** → **Deploy**
2. Search for "ComfyUI" in templates
3. Select **"ComfyUI + SDXL"** template (recommended)
4. Choose GPU:
   - **RTX 3090** (24GB VRAM) - ~$0.30/hour - RECOMMENDED
   - **RTX 4090** (24GB VRAM) - ~$0.50/hour - Best performance
   - **RTX 3080** (10GB VRAM) - ~$0.20/hour - Budget option
5. Set **Volume Size**: 50GB (to store models)
6. Click **Deploy On-Demand**

### Step 3: Access ComfyUI

1. Wait 1-2 minutes for pod to start
2. Click **Connect** → **HTTP Service** (usually port 3000 or 7860)
3. You should see ComfyUI web interface
4. Copy the pod URL (e.g., `https://xyz123-7860.proxy.runpod.net`)

### Step 4: Download Models

In ComfyUI interface:

1. Go to **Manager** → **Model Manager**
2. Download these models:
   - **Stable Diffusion XL Turbo** (~7GB)
   - **FLUX Schnell** (if you have 24GB VRAM) (~24GB)
3. Wait for downloads to complete (10-30 minutes)

### Step 5: Test Generation

In ComfyUI:

1. Load default workflow
2. Enter prompt: "beautiful landscape, mountains, lake, sunset, photorealistic"
3. Click **Queue Prompt**
4. Wait 10-20 seconds
5. Image should generate successfully ✅

### Step 6: Get API Access

Your ComfyUI endpoint is: `https://[POD_ID]-7860.proxy.runpod.net`

Test with curl:

```bash
curl -X GET https://[POD_ID]-7860.proxy.runpod.net/system_stats
```

Should return system stats JSON.

### Step 7: Configure Firebase Functions

```bash
# Set ComfyUI endpoint as Firebase secret
firebase functions:secrets:set COMFYUI_ENDPOINT

# When prompted, enter your RunPod ComfyUI URL:
# https://xyz123-7860.proxy.runpod.net

# Deploy functions
npm run deploy
```

### Step 8: Test from Backend

```bash
# Test native AI generation
curl -X POST https://aiimage-6yae5n5fjq-uc.a.run.app \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Nigerian restaurant logo, Jollof rice theme",
    "task": "image-generation"
  }'
```

Should return base64 image generated by YOUR GPU! 🎉

## OPTION 2: Vast.ai GPU (Cheapest Option)

Vast.ai is a marketplace for renting GPUs from individuals. Much cheaper than RunPod.

### Step 1: Create Vast.ai Account

1. Go to https://vast.ai
2. Sign up for an account
3. Add credits ($5 minimum)

### Step 2: Find GPU Instance

1. Go to **Instances** → **Create**
2. Search filters:
   - **GPU**: RTX 3090 or RTX 4090
   - **VRAM**: Minimum 16GB
   - **Disk Space**: Minimum 50GB
   - **DLPerf**: Minimum 50 (connection speed)
3. Sort by **$/hr** (cheapest first)
4. Select instance (~$0.15-0.30/hr)

### Step 3: Launch with Docker

Use this Docker image for ComfyUI:

```bash
# SSH into instance
ssh root@[INSTANCE_IP] -p [PORT]

# Pull ComfyUI Docker image
docker pull sickcodes/comfyui:latest

# Run ComfyUI
docker run -d \
  --gpus all \
  -p 7860:7860 \
  -v /workspace/ComfyUI:/root/ComfyUI \
  sickcodes/comfyui:latest
```

### Step 4: Download Models

```bash
# SSH into container
docker exec -it [CONTAINER_ID] bash

# Download SDXL Turbo
cd /root/ComfyUI/models/checkpoints
wget https://huggingface.co/stabilityai/sdxl-turbo/resolve/main/sd_xl_turbo_1.0_fp16.safetensors

# Download VAE
cd /root/ComfyUI/models/vae
wget https://huggingface.co/stabilityai/sdxl-vae/resolve/main/sdxl_vae.safetensors
```

### Step 5: Test & Configure

Same as RunPod steps 5-8 above.

## OPTION 3: Self-Hosted GPU (Best for Production)

If you have a gaming PC with NVIDIA GPU (RTX 3090/4090), you can host for free!

### Requirements

- **GPU**: NVIDIA RTX 3080 (10GB VRAM) or better
- **RAM**: 32GB minimum (64GB recommended)
- **Storage**: 500GB SSD
- **OS**: Windows 10/11 or Ubuntu 22.04
- **Internet**: 100Mbps+ upload speed
- **Static IP or DDNS** (for remote access)

### Step 1: Install CUDA & PyTorch

**Windows:**
```powershell
# Download CUDA 12.1 from NVIDIA
# https://developer.nvidia.com/cuda-downloads

# Install Python 3.10
# https://www.python.org/downloads/

# Install PyTorch with CUDA
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

**Linux:**
```bash
# Install CUDA
sudo apt update
sudo apt install nvidia-driver-535 nvidia-cuda-toolkit

# Install Python 3.10
sudo apt install python3.10 python3.10-venv python3-pip

# Install PyTorch
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### Step 2: Install ComfyUI

```bash
# Clone ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI

# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Step 3: Download Models

```bash
# Create models directory
mkdir -p models/checkpoints
mkdir -p models/vae

# Download SDXL Turbo (7GB)
cd models/checkpoints
curl -L -o sd_xl_turbo_1.0_fp16.safetensors \
  https://huggingface.co/stabilityai/sdxl-turbo/resolve/main/sd_xl_turbo_1.0_fp16.safetensors

# Download VAE (335MB)
cd ../vae
curl -L -o sdxl_vae.safetensors \
  https://huggingface.co/stabilityai/sdxl-vae/resolve/main/sdxl_vae.safetensors
```

### Step 4: Start ComfyUI Server

```bash
# Start server (listen on all interfaces)
python main.py --listen 0.0.0.0 --port 7860

# Server will start at http://0.0.0.0:7860
# Access from same network: http://[LOCAL_IP]:7860
```

### Step 5: Expose to Internet (Optional)

**Option A: Ngrok (Easy, Free Tier)**
```bash
# Download ngrok: https://ngrok.com/download
# Sign up for free account

# Expose ComfyUI
ngrok http 7860

# Copy the HTTPS URL (e.g., https://abc123.ngrok.io)
```

**Option B: CloudFlare Tunnel (Free, Better)**
```bash
# Install cloudflared
# https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation

# Create tunnel
cloudflared tunnel --url http://localhost:7860

# Copy the public URL
```

**Option C: Port Forwarding (Advanced)**
```
1. Log into your router admin panel
2. Forward port 7860 to your PC's local IP
3. Set up Dynamic DNS (DuckDNS, No-IP)
4. Access via: https://[YOUR_DOMAIN]:7860
```

### Step 6: Configure Firebase Functions

```bash
# Set your ComfyUI endpoint
firebase functions:secrets:set COMFYUI_ENDPOINT

# Enter your public URL:
# https://abc123.ngrok.io (Ngrok)
# https://xyz.trycloudflare.com (CloudFlare)
# https://yourdomain.duckdns.org:7860 (Port Forward)

# Deploy
npm run deploy
```

### Step 7: Test End-to-End

From your 9JAI app:

1. Open chat
2. Type: "Generate image of Nigerian Jollof rice, professional food photography"
3. Wait 10-20 seconds
4. Image should generate using YOUR GPU! 🎉

Check logs:
```bash
firebase functions:log --only aiimage
```

## TROUBLESHOOTING

### "Native GPU infrastructure not available"

**Check ComfyUI is running:**
```bash
curl http://[YOUR_ENDPOINT]/system_stats
```

Should return JSON with system info.

**If failed:**
- Check ComfyUI server is running
- Check firewall allows port 7860
- Check COMFYUI_ENDPOINT secret is set correctly

### "Image generation timed out"

**Possible causes:**
1. **Model not downloaded** - Check `ComfyUI/models/checkpoints/`
2. **Out of VRAM** - Use smaller model or reduce resolution
3. **GPU offline** - Check `nvidia-smi` shows GPU

**Fix:**
```bash
# Check GPU status
nvidia-smi

# Check ComfyUI logs
docker logs [CONTAINER_ID]  # If using Docker
# or check terminal where ComfyUI is running
```

### "Validation FAIL: Image too small"

Image generation worked but returned placeholder.

**Fix:**
- Check ComfyUI workflow actually saved image
- Check `/view` endpoint returns real image
- Try generating from ComfyUI web UI first

### "CUDA out of memory"

Your GPU doesn't have enough VRAM.

**Fix:**
1. Use smaller model (SDXL Turbo instead of FLUX)
2. Reduce image resolution (512x512 instead of 1024x1024)
3. Close other GPU applications
4. Upgrade to GPU with more VRAM

## SUPPORT

If you run into issues:

1. Check ComfyUI logs for errors
2. Test generation directly in ComfyUI web UI
3. Verify GPU is detected: `nvidia-smi`
4. Check Firebase Functions logs: `firebase functions:log`
5. Review backend logs for provider attempt chain

Common issues are usually:
- Model files not downloaded
- CUDA/GPU drivers not installed
- Endpoint URL incorrect in Firebase secrets
- Firewall blocking port 7860
