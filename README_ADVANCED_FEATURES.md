## 🎯 What is 9jai?

9jai is an AI-powered platform for learning Nigerian languages with advanced features including:

- 🗣️ **Language Learning** - Learn Edo, Yoruba, Igbo, Hausa, and 40+ Nigerian languages
- 🤖 **Professor-Level AI** - Get help with coding, web development, and education
- 📚 **Learning Hub** - Access structured tutorials and code examples
- 🎨 **Image Generator** - Create images from text descriptions
- 💾 **Persistent Chat** - Your conversations are automatically saved

## ✨ New Features (v2.0)

### 1. Enhanced AI Assistant

The AI now has professor-level expertise in:

- **Language Learning:** Teach greetings, phrases, grammar, pronunciation, and cultural context
- **Software Development:** Write code in any language, debug, optimize, and explain algorithms

### 2. Session Persistence

Your conversations are automatically saved:

- ✅ Chat history persists across browser sessions
- ✅ Active language page remembered after refresh
- ✅ Multiple language sessions supported
- ✅ No data loss on page refresh

**How It Works:**
1. Start a conversation in any language
2. Your messages are automatically saved
3. Close the browser or refresh the page
4. Your chat history and active page are restored

### 3. Education Hub

Access comprehensive learning materials:

- 📖 **Learning Materials:** Structured courses on web development, React, Python, and more
- 💻 **Code Examples:** Ready-to-use code snippets in JavaScript, Python, and other languages
- 🔍 **Search & Filter:** Find materials by keyword, difficulty level, or category
- 📚 **Learning Paths:** Suggested learning sequences for different skill levels

**How to Access:**
1. Click the "Learn" button at the bottom of the chat
2. Browse materials or code examples
3. Click on any material to view full content
4. Access external resources for deeper learning

### 4. Image Generator

Create images from text descriptions:

- 🎨 **Text-to-Image:** Describe what you want, AI generates it
- 📸 **Image History:** View all previously generated images
- ⬇️ **Download:** Save images to your device
- 📤 **Share:** Share images via native share or copy URL

**How to Use:**
1. Click the "Create" button at the bottom of the chat
2. Describe the image you want in detail
3. Click "Generate Image"
4. Download or share the generated image

- **Frontend:** React + TypeScript

- **Animations:** Framer Motion
- **AI:** Groq API
- **Backend:** Firebase (Firestore, Hosting)
- **Storage:** Browser localStorage
- **Voice:** Web Speech API

- **Initial Load:** ~2.5 seconds
- **Chat Response:** ~1-3 seconds
- **Image Generation:** ~5-15 seconds
- **Session Restore:** <100ms
- **Bundle Size:** 1,365 KB (gzipped: 360 KB)

## 🆘 Troubleshooting

### Chat History Not Saving
- Check if localStorage is enabled in browser
- Clear browser cache and try again
- Try a different browser

### Image Generation Not Working
- Check internet connection
- Try a simpler prompt
- Wait a few seconds and try again
- Fallback images will display if API unavailable

### Education Hub Not Loading
- Refresh the page
- Clear browser cache
- Try a different browser

### AI Not Responding
- Click the stop button (red square)
- Try a simpler question
- Refresh the page

---

## 🔐 Privacy & Security

### Your Data
- **Saved Locally:** All chat history saved in your browser
- **Not Uploaded:** Your conversations don't go to external servers
- **Private:** Only you can see your chat history
- **Secure:** Uses HTTPS for all connections

### Clearing Data
To delete all saved data:
1. Open browser developer tools (F12)
2. Go to Application → Local Storage
3. Delete entries starting with "user_sessions"
4. Refresh the page
