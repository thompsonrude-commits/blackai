# Architecture Glossary

- AI Service: Top-level orchestration service for coordinating platform requests.
- AI Orchestrator: Request routing and execution coordination service.
- Capability Registry: The registry of available engines, tools, and services.
- Connector Platform: Authentication, registry, webhook, retry, and monitoring layer for external integrations.
- Knowledge Engine: Retrieval and indexing engine for knowledge documents and semantic search.
- Memory Engine: Session and long-term memory context management engine.
- Operations Center: Monitoring, metrics, alerting, incident, reporting, and readiness services.
- Release Engineering: Packaging, validation, upgrade, rollback, and certification services.
- Security Platform: Identity, authorization, secrets, encryption, and audit services.
- Runtime: Execution environment for inference, workflows, and task dispatch.
