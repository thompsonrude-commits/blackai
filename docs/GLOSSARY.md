# Engineering Glossary

- Capability registry: catalog of engines, tools, providers, and services available to the platform
- Connector platform: standard interface for authentication, sync, retries, and webhook management
- Knowledge engine: service managing indexed documents and semantic retrieval
- Memory engine: service managing short-term and long-term context
- Orchestrator: service responsible for coordinating pipelines and execution plans
- Runtime: execution environment for engine and model invocation
- Security platform: central governance layer for identity, policy, secrets, and audit
